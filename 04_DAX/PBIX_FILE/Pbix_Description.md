# DAX Practice Workbook

## Overview

This Power BI workbook was created while learning and practicing Data Analysis Expressions (DAX). It contains various measures, calculated columns, and business calculations developed using the Awesome Chocolates dataset.

## Concepts Demonstrated

- DAX Measures
- Calculated Columns
- Measure Reusability
- Evaluation Context
- Filter Context
- CALCULATE() Function
- IF() Statements
- DISTINCTCOUNT()
- MIN(), MAX(), AVERAGE()
- DIVIDE()
- Variables (VAR)
- IN Operator
- Multiple Filters with CALCULATE()

## Purpose

The objective of this workbook was to understand how DAX can be used to create dynamic calculations, business KPIs, and analytical metrics that respond to filters and slicers in Power BI reports.

## Skills Demonstrated

- DAX Development
- Business Calculations
- Measure Creation
- Data Analysis
- Context-Aware Calculations
- Performance-Oriented Modeling

## Learning Outcome

Through this practice workbook, I gained hands-on experience in creating reusable DAX measures, modifying filter context with CALCULATE(), implementing conditional logic, and building calculations that support business reporting and dashboard development.
