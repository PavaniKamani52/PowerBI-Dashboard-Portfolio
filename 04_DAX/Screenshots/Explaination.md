# DAX Screenshots

## Overview

This folder contains screenshots captured while learning and practicing DAX (Data Analysis Expressions) in Power BI.

The screenshots demonstrate various DAX concepts, calculations, and business metrics created using the Awesome Chocolates dataset.

## Topics Demonstrated

* Measure Creation
* Measure Formatting
* Evaluation Context
* Measure Reusability
* IF() Conditions
* DISTINCTCOUNT()
* MIN(), MAX(), AVERAGE()
* CALCULATE() Function
* Multiple Filters
* Variables (VAR)
* KPI Calculations
* Business Metrics

## Purpose

These screenshots serve as visual references for the DAX concepts and examples implemented throughout the learning process.

## Learning Outcome

Through these exercises, I gained practical experience in creating dynamic calculations, understanding filter context, and building reusable DAX measures for business reporting and analytics.
