# SQL Integration & Power Query Transformations

This project demonstrates the process of connecting Power BI to a SQL database, importing multiple business tables, and transforming raw data into an analysis-ready dataset using Power Query.

The workflow covers data extraction, cleaning, feature engineering, and preparation techniques commonly used in real-world business intelligence projects.

## Key Activities

### SQL Data Import
- Connected Power BI to a SQL database.
- Imported multiple related tables using the Navigator interface.
- Previewed and selected relevant datasets for analysis.

### Power Query Transformations
- Cleaned and standardized data.
- Verified and corrected data types.
- Removed unnecessary fields.
- Created custom columns and derived attributes.
- Applied date transformations and business logic.
- Prepared data for reporting and dashboard development.

### Feature Engineering
Created additional fields such as:
- Day Name
- Day of Week
- Booking Lead-Time Buckets
- Business-friendly categorization columns
