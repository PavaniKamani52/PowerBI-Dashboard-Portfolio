# Netflix Data Cleaning & Exploratory Data Analysis (EDA)

## Overview

This project demonstrates the use of Power Query in Power BI to clean, transform, and analyze a real-world Netflix dataset. The objective was to prepare raw data for analysis, improve data quality, and uncover meaningful insights through Exploratory Data Analysis (EDA).

The project focuses on data preparation techniques such as handling missing values, data profiling, text transformations, feature engineering, and date standardization before building analytical visualizations.

---

## Dataset

**Source:** Netflix Titles Dataset (Kaggle)

The dataset contains information about Netflix Movies and TV Shows, including:

* Title
* Type
* Director
* Cast
* Country
* Release Year
* Rating
* Duration
* Genre
* Description

---

## Power Query Transformations

### Data Cleaning

* Fixed column headers
* Corrected data types
* Removed unnecessary fields
* Filtered irrelevant records

### Missing Value Treatment

* Identified blank and null values
* Replaced missing entries where applicable
* Improved overall data quality

### Data Profiling

* Column Quality Analysis
* Column Distribution Analysis
* Column Profile Review

### Feature Engineering

* Extracted useful attributes
* Created analysis-friendly columns
* Simplified categorical information

### Date Transformation

* Standardized date formats
* Cleaned inconsistent date values
* Prepared data for time-series analysis

### Text Transformation

* Split text fields
* Extracted keywords
* Performed basic sentiment categorization

The cleaned dataset was used to answer several business questions:

### Content Distribution

* Movies vs TV Shows

### Country Analysis

* Countries contributing the highest number of titles
* Geographic distribution of Netflix content

### Release Year Trends

* Growth of Netflix content over time
* Peak content production periods

### Text-Based Analysis

* Interesting word identification
* Content description exploration
