# Power Query Fundamentals

## What is Power Query?

Power Query is the data preparation and transformation engine in Power BI. It is used to connect, clean, transform, and prepare data before analysis and visualization.

Power Query follows the ETL process:

* Extract Data
* Transform Data
* Load Data

---

## Why Power Query is Important

Power Query helps analysts:

* Clean messy datasets
* Automate repetitive tasks
* Combine data from multiple sources
* Improve data quality
* Prepare data for reporting

---

## Power Query Editor

The Power Query Editor is where all data transformations are performed.

### Main Components

#### Queries Pane

Displays all imported queries.

#### Data Preview Window

Shows the current dataset.

#### Applied Steps

Records every transformation performed.

#### Formula Bar

Displays M code generated by Power Query.

## Web Scraping

Power Query can extract tabular data directly from websites.

Benefits:

* Automated data collection
* Faster updates
* Reduced manual work

Data extraction from a Wikipedia webpage.

## Data Cleaning Techniques

Common cleaning operations include:

### Filtering Data

Remove unnecessary records.

### Find and Replace

Correct inconsistent values.

### Trimming Text

Remove unwanted spaces.

### Fill Down

Replace null values using values from previous rows.

### Data Type Conversion

Convert data into correct formats.

---

## Column Quality Indicators

Power Query provides:

### Column Quality

Shows valid, empty, and error values.

### Column Distribution

Shows unique and duplicate values.

### Column Profile

Displays detailed statistics.

These tools help identify data quality issues.

---

## Data Refresh

Power Query transformations can be refreshed automatically when source data changes.

Benefits:

* Automation
* Consistency
* Reduced manual effort
