## Date Transformations

Common date operations include:

* Fixing date formats
* Standardizing date values
* Extracting Year

* Extracting Day

Tenure can be calculated using:

This helps analyze employee experience levels.

## Text Transformations

Power Query provides several text functions.

Examples:

* Trim
* Clean
* Uppercase
* Lowercase
* Capitalize
* Extract Text
* Split Columns

These improve consistency and data quality.

---

## Splitting Columns

Columns can be split by:

* Delimiters
* Fixed Positions
* Custom Rules

Example:

Full Name

John Smith

Can be split into:

* First Name
* Last Name

---

## Conditional Columns

Conditional Columns create rule-based categories.

Example:

If Salary > 50000

Then "High Salary"

Else "Medium Salary"

Useful for business segmentation.

---

## Custom Columns

Custom columns allow new calculations using formulas.

Examples:

* Salary Buckets
* Tenure Calculations
* Business Categories
* Derived Metrics

---

## M Code Basics

Power Query transformations are written using the M language.

Example Applications:

* Custom calculations
* Advanced transformations
* Query automation

Power Query automatically generates M code for most actions.
