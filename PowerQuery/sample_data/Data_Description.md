# Power Query

## Overview

This section covers Power Query, the data transformation and preparation engine used in Power BI. Through hands-on practice with real-world datasets, I learned how to clean, transform, profile, and prepare data for analysis and reporting.

Power Query plays a critical role in the data preparation process by enabling efficient ETL (Extract, Transform, Load) workflows before building data models and dashboards.
