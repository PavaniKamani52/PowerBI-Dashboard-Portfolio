# Hotel Reservation Analytics Dashboard

## Project Overview

This project is an end-to-end Power BI dashboard developed to analyze hotel reservation data and identify booking patterns, customer behavior, loyalty trends, and stay preferences.

The dashboard was built by performing data preparation, creating custom columns, developing DAX measures, and designing interactive visualizations to generate actionable business insights.

## Data Preparation & Transformations

The following transformations were performed using Power Query:

* Cleaned and validated reservation data.
* Created a **Day Name** column from booking dates.
* Created a **Day of Week Number** column for proper weekday sorting.
* Calculated **Booking Lead Time** to analyze how far in advance customers make reservations.
* Derived booking and stay-related metrics from date fields.
* Removed unnecessary columns and optimized data types.
* Prepared the dataset for reporting and analysis.

## Data Modeling

* Built a semantic model for hotel reservation reporting.
* Organized booking data for efficient analysis.
* Created measures and calculated fields required for dashboard KPIs.

## DAX Calculations

Created measures for:

* Total Reservations
* Total Revenue
* Average Room Rate
* Average Lead Time
* Loyalty Customer Count
* Non-Loyalty Customer Count
* Weekend vs Weekday Stay Analysis
