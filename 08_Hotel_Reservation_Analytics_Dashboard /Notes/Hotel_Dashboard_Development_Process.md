# Hotel Reservation Dashboard – Notes

## Overview
This project demonstrates the end-to-end development of a Hotel Reservation Dashboard in Power BI. The report focuses on analyzing booking trends, customer behavior, loyalty programs, revenue performance, and occupancy patterns to generate actionable business insights.

## Key Concepts Covered

### Data Preparation
- Imported hotel reservation data into Power BI.
- Cleaned and transformed data using Power Query.
- Created additional columns for booking analysis such as:
  - Day Name
  - Day of Week
  - Booking Lead Time
  - Stay Duration Categories

### Data Modeling
- Built a semantic model for reporting.
- Organized booking data and created relationships where required.
- Optimized the model for efficient analysis.

### DAX Calculations
Created measures for:
- Booking Count
- Cancellation Count
- Cancellation Percentage
- Total Revenue
- Average Room Rate
- Total Room Nights
- Loyal Customer Bookings
- Non-Loyal Customer Bookings

### Dashboard Visualizations
Implemented multiple visual types:
- KPI Cards
- Line Charts
- Column Charts
- Bar Charts
- Pie Charts
- Matrix Visuals
- Slicers
- Conditional Formatting

### Business Insights Generated
- Booking trends over time.
- Weekday vs Weekend stay patterns.
- Customer loyalty analysis.
- Booking lead-time analysis.
- Revenue and occupancy monitoring.
- Booking channel performance comparison.

### Dashboard Design
- Applied report themes and custom colors.
- Added navigation buttons and slicers.
- Designed an executive-friendly layout.
- Improved storytelling through visual arrangement.

## Learning Outcomes
- Power Query data preparation.
- Data modeling best practices.
- DAX measure creation.
- KPI dashboard development.
- Customer and revenue analysis.
- Report design and storytelling in Power BI.
