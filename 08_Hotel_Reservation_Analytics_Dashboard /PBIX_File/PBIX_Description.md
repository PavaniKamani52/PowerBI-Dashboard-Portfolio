# Hotel Reservation Analytics Dashboard

## Overview

This Power BI dashboard was developed to analyze hotel reservation data and provide actionable insights into customer behavior, booking patterns, and business performance.

The project combines Power Query transformations, data modeling, DAX calculations, and interactive visualizations to create a comprehensive reporting solution for hotel management.

## Dashboard Features

* Booking Trend Analysis
* Weekday vs Weekend Stay Analysis
* Loyalty Program Analysis
* Booking Channel Performance
* Customer Segmentation
* Revenue Monitoring
* KPI Cards and Performance Metrics
* Interactive Filters and Slicers
* Matrix Visual with Conditional Formatting

## Visualizations Used
