# Data Modeling

## Overview

This section focuses on Data Modeling and Semantic Modeling in Power BI using the Awesome Chocolates dataset. The objective was to understand how multiple tables can be connected through relationships to create a scalable and efficient analytical model.

A well-designed data model improves report performance, simplifies DAX calculations, and enables accurate business analysis.
