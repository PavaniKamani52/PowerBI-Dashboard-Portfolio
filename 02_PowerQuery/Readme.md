# Power Query

## Overview

This section documents my learning and hands-on practice with Power Query in Power BI. Power Query is the data transformation and preparation engine used to clean, shape, and prepare raw data before analysis and reporting.

Through real-world datasets and practical exercises, I learned how to perform data cleaning, feature engineering, exploratory data analysis (EDA), SQL data integration, and transformation workflows that are commonly used in business intelligence projects.
