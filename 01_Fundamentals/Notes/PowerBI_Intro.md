# Power BI Fundamentals

## What is Power BI?

Power BI is a Business Intelligence (BI) and Data Visualization tool developed by Microsoft. It enables users to connect to data sources, transform data, create visualizations, build dashboards, and share business insights.

### Common Use Cases

* Sales Analysis
* Financial Reporting
* HR Analytics
* Customer Analytics
* Executive Dashboards

---

## Power BI Components

### Power BI Desktop

Used for data modeling, report development, DAX calculations, and dashboard creation.

### Power BI Service

Cloud-based platform used for publishing, sharing, collaboration, and scheduled refreshes.

### Power BI Mobile

Used to access reports and dashboards from mobile devices.

### Power BI Gateway

Provides secure access to on-premises data sources.

---

## Power BI Desktop Interface

### Ribbon

Contains commands for data loading, transformations, modeling, and report creation.

### Report View

Used for creating and designing reports.

### Data View

Used to view imported datasets.

### Model View

Used to create and manage table relationships.

### Visualizations Pane

Contains chart and visual options.

### Filters Pane

Used to apply report, page, and visual-level filters.

---

## Data Loading

Power BI can connect to multiple data sources:

* Excel
* CSV
* SQL Server
* Web
* Folder
* SharePoint

### Steps

1. Click Get Data
2. Select Data Source
3. Preview Data
4. Load or Transform Data

---

## Saving Reports

Power BI reports are saved using the `.pbix` format.

A PBIX file contains:

* Data model
* Visualizations
* DAX measures
* Report pages
* Power Query transformations

---

## Publishing Reports

Reports can be published to Power BI Service.

### Steps

1. Save the report
2. Click Publish
3. Select Workspace
4. Upload the report

### Benefits

* Online access
* Collaboration
* Scheduled refresh
* Dashboard sharing

---

## Power BI Desktop vs Service

| Feature         | Desktop | Service |
| --------------- | ------- | ------- |
| Report Creation | Yes     | Limited |
| Data Modeling   | Yes     | No      |
| DAX Development | Yes     | No      |
| Publishing      | Yes     | No      |
| Sharing         | No      | Yes     |
| Collaboration   | No      | Yes     |

### Summary

Power BI Desktop is used for report development.

Power BI Service is used for report sharing, collaboration, and management.
