# Dataset Description

## Overview

This dataset contains chocolate sales transaction data used for learning Power BI fundamentals and report creation.

The dataset includes sales information across multiple countries, products, sales representatives, and dates. It was used to practice data loading, visualization creation, filtering, report interactions, and dashboard development in Power BI.

## Dataset Source

Dataset used from Chandoo's Power BI learning tutorials.

## Columns

| Column Name | Description |
|------------|-------------|
| Sales Person | Name of the salesperson responsible for the sale |
| Country | Country where the sale occurred |
| Product | Product sold |
| Date | Transaction date |
| Amount | Sales revenue generated |
| Boxes Shipped | Number of product boxes shipped |
