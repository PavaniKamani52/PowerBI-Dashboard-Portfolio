# SQL Integration with Power BI

## Overview

This module demonstrates how SQL and Power BI work together in a real-world analytics workflow. The objective is to extract, transform, and analyze data stored in relational databases and build interactive reports in Power BI.

The project covers connecting Power BI to SQL databases, importing data, writing SQL queries, creating relationships, and developing business insights through dashboards.

---

## Learning Objectives

* Connect Power BI to SQL databases
* Import tables and views from SQL Server/MySQL
* Use SQL queries for data extraction and filtering
* Perform data transformations in Power Query
* Build relationships between SQL tables
* Create a semantic model for reporting
* Develop DAX measures on SQL-based datasets
* Design interactive dashboards and reports
