# Semantic Model & Star Schema

This project demonstrates Data Modeling and Semantic Modeling in Power BI using the Awesome Chocolates dataset. A Star Schema was created with the **Shipments** table as the central Fact Table and **Products, People, Locations, and Calendar** as Dimension Tables connected through one-to-many relationships.

The model enables efficient filtering, accurate analysis, and improved report performance. Through this exercise, I learned how to create relationships, implement a Star Schema, understand filter propagation, and build a scalable data model that serves as the foundation for DAX calculations, visualizations, and dashboard development.

**Skills Demonstrated:** Data Modeling, Semantic Modeling, Star Schema Design, Relationship Management, Fact & Dimension Tables, Filter Propagation, Evaluation Context, and Power BI Model Optimization.
