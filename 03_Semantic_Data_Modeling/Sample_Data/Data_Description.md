# Awesome Chocolates SQL Dataset

## Overview

This SQL dataset contains business data for the fictional Awesome Chocolates company. It was used to practice SQL integration with Power BI, data modeling, and business reporting.

The dataset is structured as a relational database and includes multiple tables connected through keys and relationships.

## Tables Included

### Sales
Contains transaction-level sales records, including:
- Sales Amount
- Product IDs
- Customer Information
- Salesperson Information
- Transaction Dates

### Products
Contains product-related information such as:
- Product ID
- Product Name
- Product Category

### People
Contains salesperson information:
- Salesperson ID
- Salesperson Name
- Team

### Geography
Contains location details:
- Country
- Region
- Geography ID

## Purpose

This dataset was used for:

- SQL to Power BI Integration
- Data Import using SQL Queries
- Data Modeling
- Star Schema Design
- Relationship Creation
- Business Analysis
- Dashboard Development

## Skills Demonstrated

- SQL Database Connectivity
- Data Extraction
- Relational Data Modeling
- Power BI Integration
- Business Intelligence Reporting

## Learning Outcome

Using this dataset, I learned how to connect Power BI to a SQL database, import multiple related tables, establish relationships, and prepare data for analysis and dashboard creation.
