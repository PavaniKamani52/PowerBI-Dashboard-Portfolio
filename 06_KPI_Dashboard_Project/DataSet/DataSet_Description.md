# Dataset Description

## Actual vs Target Dataset

This dataset is designed for building a Finance KPI Dashboard in Power BI and focuses on comparing actual sales performance against predefined targets.

## Dataset Structure

### Actual

Contains actual sales values achieved by each salesperson across multiple months.

Key Fields:

* Sales Person
* Monthly Sales Values (Jan 2023 – Feb 2024)

### Targets

Contains monthly target values assigned to each salesperson.

Key Fields:

* Sales Person
* Monthly Target Values (Jan 2023 – Feb 2024)

### Calendar

Date dimension table used for time-based analysis.

Key Fields:

* Date

### dimPeople

Salesperson dimension table containing team information and profile references.

Key Fields:

* Sales Person
* Team
* Picture

## Purpose of the Dataset

The dataset is used to:

* Compare Actual vs Target Performance
* Build KPI Dashboards
* Perform Variance Analysis
* Track Monthly Trends
* Analyze Salesperson Performance
* Create YTD Metrics
* Develop Executive Reports

## Concepts Demonstrated

* Data Transformation using Power Query
* Unpivoting Monthly Data
* Data Modeling with Multiple Tables
* Relationship Creation
* DAX Measures
* YTD Calculations
* Variance Analysis
* KPI Development
* Dashboard Storytelling

## Business Questions Answered

* Are sales targets being achieved?
* Which salespeople are performing best?
* What is the monthly performance trend?
* How much variance exists between actual and target values?
* Which teams are contributing the most to business performance?

## Learning Outcome

This dataset provides a practical scenario for building an end-to-end Finance KPI Dashboard by combining data preparation, modeling, DAX calculations, and executive-level reporting in Power BI.
