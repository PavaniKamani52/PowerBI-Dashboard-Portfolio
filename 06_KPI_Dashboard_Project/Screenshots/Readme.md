# Power BI KPI Dashboard & Advanced Visualizations

## Overview

This project demonstrates the creation of interactive KPI dashboards and advanced visualizations in Power BI using business sales and shipment data. The reports focus on transforming raw data into meaningful insights through effective visual storytelling and performance tracking.

## Key Features

### KPI Reporting

* Total Amount KPI
* Total Boxes KPI
* Shipment Count KPI
* Target vs Actual Comparison
* Performance Indicators using Emoji and Star Ratings

### Visualizations Used

* KPI Cards
* Stacked Column Charts
* Line Charts
* Donut Charts
* Matrix Visuals
* Tables
* Sparklines
* Conditional Formatting

### Business Analysis

* Geo-wise Sales Analysis
* Category-wise Revenue Breakdown
* Monthly Shipment Trends
* Team Performance Analysis
* Salesperson Performance Tracking
* Target Achievement Monitoring

### Advanced Power BI Features

* DAX Measures
* KPI Comparisons
* Emoji-based Performance Indicators
* Star Rating System
* Custom Data Labels
* Sparklines in Tables
* Conditional Formatting
* Interactive Filtering

## Skills Demonstrated

* Power BI Dashboard Design
* KPI Development
* Data Visualization
* DAX Calculations
* Business Intelligence Reporting
* Executive Dashboard Creation
* Performance Analysis
* Data Storytelling

## Learning Outcomes

Through this project, I gained practical experience in building KPI dashboards, creating advanced visualizations, implementing business metrics, and designing executive-level reports that support data-driven decision making.
