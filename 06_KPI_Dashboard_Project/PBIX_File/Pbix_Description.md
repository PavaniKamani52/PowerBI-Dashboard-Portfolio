# Finance KPI Dashboard

## Overview

This Power BI dashboard was developed to analyze and monitor key financial performance indicators (KPIs) through an interactive and executive-friendly reporting solution.

The project combines data preparation, semantic modeling, DAX calculations, and visualization techniques to transform raw business data into meaningful insights.

## Dashboard Features

* KPI Cards for key business metrics
* Year-to-Date (YTD) Analysis
* Variance and Performance Tracking
* Monthly Trend Analysis
* Sales Performance Reporting
* Interactive Filters and Slicers
* Smart Narrative Insights
* Executive Reporting Layout

## Concepts Demonstrated

* Power Query Transformations
* Data Modeling with Multiple Fact Tables
* DAX Measures and Calculations
* FILTER() Function
* YTD Calculations
* KPI Development
* Dashboard Storytelling
* Business Intelligence Reporting

## Skills Demonstrated

* Power BI Development
* Financial Analytics
* Data Visualization
* KPI Reporting
* DAX Calculations
* Interactive Dashboard Design
* Executive Reporting

## Learning Outcome

This project helped strengthen my understanding of end-to-end Power BI development by integrating data preparation, modeling, calculations, and visualization into a complete KPI dashboard for business performance analysis.
