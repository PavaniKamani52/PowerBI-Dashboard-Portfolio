# Finance KPI Dashboard

## Overview

This project demonstrates the creation of an interactive Finance KPI Dashboard in Power BI. The dashboard transforms raw financial data into actionable business insights by combining data preparation, data modeling, DAX calculations, and effective data visualization techniques.

The objective of this project is to monitor key financial metrics, track business performance, and support data-driven decision-making through an executive-level dashboard.

## Project Workflow

### 1. Data Preparation

Data was imported and transformed using Power Query.

Key transformations included:

* Data cleaning
* Data shaping
* Unpivoting columns
* Preparing data for analysis

### 2. Data Modeling

A semantic model was created using multiple related tables.

Topics covered:

* Table relationships
* Multiple fact tables
* Data model optimization
* Filter propagation

### 3. DAX Calculations

Several DAX measures were created to support KPI reporting.

Examples include:

* YTD (Year-to-Date) calculations
* Variance analysis
* FILTER() function
* Business performance indicators
* Dynamic KPI calculations

### 4. Dashboard Development

The dashboard was designed to provide a clear view of financial performance.

Features include:

* KPI Cards
* Reference Labels
* Monthly Trend Analysis
* Sales Performance Tables
* Sparklines
* Custom Data Labels
* Interactive Filtering
* Smart Narrative Insights
* Executive Reporting Layout
