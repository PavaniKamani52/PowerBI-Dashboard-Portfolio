## HR Data Visualization Dashboard

This Power BI project focuses on HR analytics and employee workforce insights using a dataset of 14,999 employees.

The dashboard demonstrates the use of various Power BI visualizations to analyze employee distribution, attrition trends, salary levels, department-wise workforce composition, project allocation, working hours, promotions, and employee tenure.

### Visualizations Covered
- Bar Charts
- Column Charts
- Line Charts
- Pie / Donut Charts
- KPI Cards
- Tables
- Matrix Visuals
- Slicers and Filters

### Key Analysis Areas
- Employee Headcount Analysis
- Department-wise Distribution
- Employee Attrition Tracking
- Salary Category Analysis
- Working Hours Analysis
- Project Allocation Insights
- Promotion Analysis
- Employee Tenure Trends

### Skills Demonstrated
- Data Visualization
- Dashboard Design
- Interactive Reporting
- HR Analytics
- Data Exploration
- Business Intelligence Reporting

This project helped strengthen my understanding of Power BI visualizations, report design principles, and HR data analysis through interactive dashboards.
