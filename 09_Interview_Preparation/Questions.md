# Power BI Interview Questions & Answers

## Overview

This repository contains a collection of commonly asked **Power BI interview questions and answers** that help candidates prepare for Power BI Developer, Data Analyst, and Business Intelligence roles.

The questions cover essential concepts including DAX, Data Modeling, Power BI Service, Performance Optimization, Row-Level Security (RLS), and Data Transformation techniques.

---

### 1. Difference Between a Measure and a Calculated Column

* Understanding row context and filter context.
* When to use measures vs calculated columns.
* Performance considerations.

### 2. Publishing a Power BI Report to the Service

* Creating reports in Power BI Desktop.
* Publishing reports to Power BI Service.
* Managing workspaces and datasets.

### 3. Handling Missing Data

* Identifying null and missing values.
* Using Power Query transformations.
* Data cleaning best practices.

### 4. Understanding DAX (Data Analysis Expressions)

* Purpose of DAX in Power BI.
* Common DAX functions and calculations.
* Real-world examples of DAX measures.

### 5. Connecting Multiple Data Sources

* Importing data from different sources.
* Managing relationships between datasets.
* Data integration best practices.

### 6. Power BI Desktop vs Power BI Service

* Key differences between development and deployment environments.
* Collaboration and sharing capabilities.
* Scheduled refresh and cloud features.

### 7. Performance Optimization Techniques

* Reducing model size.
* Optimizing DAX calculations.
* Improving report responsiveness.
* Efficient data modeling practices.

### 8. Row-Level Security (RLS)

* Purpose of RLS.
* Creating roles and security filters.
* Testing and deploying security rules.

### 9. Understanding Relationships in Data Models

* One-to-Many (1:*)
* Many-to-One (*:1)
* Relationship directions and filtering behavior.
* Importance of proper data modeling.

### 10. Slowly Changing Dimensions (SCD)

* Overview of SCD concepts.
* Common SCD Types (Type 1 and Type 2).
* Implementing SCD strategies in Power BI and ETL processes.
